# Leader 單車 1742 mm 停車點比例驗證（2026-11-16）

前兩次 2 m 直線，操作者以 MPU6050 垂直投影讀得地面約 230 cm，Nano 車上
里程分別 2002.7／2002.9 mm。用最近一趟、且操作者未見打滑的量測固定
比例 `k=2300/2002.9=1.1483`，事前選擇本趟 Nano 停車目標
`2000/k≈1742 mm`，**沒有修改 Nano 韌體、輪徑或 PID 常數**。

操作者確認車輪接地、起點到 250 cm 與兩側淨空、馬達斷電可及。Pi 的
`leader_straight_calibration.py` 使用原本有航向修正的直線模式，
`--distance-mm 1742 --speed-mm-s 25`。接地 PWM 80／800 ms 預檢左右
ENCODER count 943／706、車上航向 −19.3°，故障旗標 0 且 STOP ACK。
預檢左右差與前趟不同；操作者檢查車輪／供電無明顯異常，將 MPU 放回
0 cm、車頭對正並再次確認淨空後才出發。

正式行走 36.713 s，到車上 `x=1743.1 mm`、`y=−2.7 mm`、航向 +0.4°，
左右 count 10406／10413，`fault_code=0`。Nano STOP ACK，Pi 控制程序退出；
F1/F2 未動。依事前固定比例預測地面終點
`1743.1 × 1.1483 ≈ 2001.7 mm`，即約 **200.2 cm**。
操作者回報地面 MPU 投影約 **200 cm**，且未見打滑。這與事前預測的
200.2 cm 相符，支持以 `k=1.1483` 暫作**直線**里程換算；約值不能證明
彎道的橫向位移與航向也同樣準確。
