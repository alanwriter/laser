# 每車 2 m 輪徑韌體的 2 m 驗收（2026-11-18）

韌體：三台都是逐輪前饋＋自己 2 m 比例的等效輪徑（Leader 74.64、F1 74.30、F2 75.05 mm；見
`firmware/builds/2026-11-18/README.md`）。程式 `leader_straight_calibration.py`（SHA `018e70a3…`），
Pi 航向修正模式，`--distance-mm 2000 --speed-mm-s 30`，接地預檢 PWM 60／600 ms。Pi 端沒有任何比例換算：
停車目標就是 2000 mm。每趟預檢後操作者把 MPU 投影放回 0 cm 再出發；三趟都 STOP ACK、程序退出、fault 0。
