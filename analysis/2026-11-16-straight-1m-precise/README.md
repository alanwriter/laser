# Leader 單車 1 m 精讀複測（2026-11-16）

## 現場條件與停止狀態

操作者用尺確認地面 0–100 cm 膠帶中心距實際為 **100 cm**，車輪接地、前方至 150 cm 淨空、馬達電源可立即切斷。接地預檢後，操作者把 Leader 的 MPU6050 垂直投影放回 0 cm 起點，車頭對正中心線並開始錄影，才授權本趟 1 m 行走。停車後用直角尺／鉛垂線讀 MPU 地面垂直投影，回報 **116 cm**。這是現場約 1 cm 分辨率的尺讀；錄影尚未提供，也沒有相機幾何標定。

只讓 Leader 行走，F1/F2 未啟動。Leader Pi 執行 `leader_straight_calibration.py`，SHA-256 `4b4b9a1e49e8d95766ffb71c667efc7ab9de8a1bc9bac75f8dae3fc99daf90ce`；與前一版相比只修正「2 m 淨空」錯誤提示為本次 1 m，控制律不變。命令為車上估計距離 1000 mm、巡航 18 mm/s，Nano `VELOCITY` 命令 180 ms 到期。IMU 校正成功；接地開環 PWM 80／800 ms 預檢左右 count 692／766，STOP ACK、預檢旗標通過。程式在最終擺位後 RESET 並行走，結束時 Nano STOP ACK、程序退出；`fault_code=0`。Pi 上 Nano USB 在 `/dev/ttyUSB0`，光達 USB 仍接著但本趟未掃描。

## 尚未釐清及下一步

目前**不能將約 5.16 count/mm 直接燒成新常數**：地面尺讀雖比前兩趟精確，仍需要同一趟獨立觀測輪子實際轉數，才能判斷差距是行走中的 encoder 漏計、輪地相對運動、量測基準，或歷史每圈 count 與現版系統不一致。A/B invalid 0 只排除偵測到的非法相位跳變，無法排除整個有效相位循環漏失。下一趟若要區分原因，應在輪胎側面貼清楚的轉數標記、固定側面相機，並同步拍地面尺與車上 MPU 標記；保持單車短直線、同一個 RESET 起點及即時斷電能力。另需分別修正低速輪速控制的起轉死區與積分限幅，不把速度超調和里程尺度混成一個參數。
