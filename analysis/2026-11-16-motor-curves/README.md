## 接下來的逐車實驗

三車依序、每次只動一台。每車以正常電池、正常載重、車輪接地和同一地面測試，
記錄車名、韌體版本、電池電壓、左右 PWM、兩輪 TPS/count、命令時間、起終點
MPU 地面位置、航向與影片。每個 PWM 配對從同一起點重新擺位；先量從靜止
起轉，再量已起轉後維持約 1–2 s 的輪速。各點至少重複三次，排除加速前段，
由後段求中位 TPS 與變動幅度。量測時設航向、路程、時間及通訊失效停止護欄；
舊 Leader PWM 40 護欄事件不會被當成有效穩態點。執行前仍需確認當下淨空、
斷電方式、車輪接地及相機，預檢後放回起點再出發。

操作者若觀察到輪胎空轉或車體滑移，該試次標為無效並重做，原始紀錄及原因
仍保留；有效試次不以打滑解釋輪速或里程誤差。左右同 PWM 不等速先作為每輪
特性量測，不由此推論卡滯。若航向護欄使配對無法維持到穩態，該點也不納入
穩態曲線，改用較接近直行的左右 PWM 配對另測。

先畫每車左右輪的「輸入 PWM → encoder TPS」，並分別標示起轉成功率與已起轉
穩態區間。只有當兩輪在同一 TPS 區域都能連續、可重複地控制，才標出該車
共同可控的 TPS 交集。TPS 換成真實地面 mm/s 需再用同一趟地面尺與輪側轉數
核對；Leader 1 m 命令停在地面 116 cm，不能直接套韌體現有 ticks/mm 當地面真值。

差速設計之後使用各輪各自的反函數選 PWM。若地面輪速為 `vL`、`vR`、有效
輪距為 `b_eff`，車體速度與角速度為 `v=(vL+vR)/2`、`ω=(vR−vL)/b_eff`。
幾何輪中心距約 137.5 mm 是起始量測值，`b_eff` 須用有效試次的左右轉彎角度
再估計；尚不能拿現有短掃描指定可靠轉彎半徑。
